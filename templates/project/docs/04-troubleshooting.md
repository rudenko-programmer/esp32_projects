# 4. Типовые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Нет COM-порта | кабель только для зарядки / нет драйвера CH9102 | [docs/esp32-arduino-setup.md](../../../docs/esp32-arduino-setup.md), раздел 3 |
| `Connecting...____` и ошибка заливки | плата не вошла в режим загрузки | зажать **BOOT** при появлении `Connecting...` |
| `Нет файла config.h` при сборке | не создан конфиг | скопировать `config.example.h` → `config.h` |
| `[WiFi]` не подключается | сеть 5 ГГц или неверный пароль | ESP32 работает только с 2.4 ГГц |

# 1. Подготовка среды и первое подключение ESP32

## 1.1 Arduino IDE, пакет ESP32, COM-порт

Общая для всех проектов часть — один раз на компьютер: [docs/esp32-arduino-setup.md](../../../docs/esp32-arduino-setup.md).
После неё должно быть: Arduino IDE 2.x, пакет **esp32 от Espressif** 3.x, плата **DOIT ESP32 DEVKIT V1** видна как `COMx`.

## 1.2 Библиотеки проекта

1. **Эскиз → Подключить библиотеку → Управлять библиотеками** (или иконка книг на левой панели).
2. Найдите **Adafruit PN532** — автор **Adafruit**.
3. Оставьте последнюю версию (проверено на **1.3.4**) и нажмите **«Установка»**.
4. На вопрос о зависимостях выберите **«Установить все»** (Install all) — так поставится **Adafruit BusIO**, без неё скетч не соберётся.

> Нужна именно свежая версия библиотеки: в режиме I2C она проверяет готовность модуля по шине, поэтому хватает 4 проводов (см. [04-hardware.md](04-hardware.md), раздел 4.4). Старые версии требовали отдельный провод IRQ.

Остальное (`WiFi`, `HTTPClient`, `WiFiClientSecure`, `Wire`) входит в пакет ESP32.

Через arduino-cli:

```powershell
arduino-cli lib install "Adafruit PN532"
```

Дальше: [02-webhook-server.md](02-webhook-server.md) — поднять сервер (он даст IP и ключ для прошивки).

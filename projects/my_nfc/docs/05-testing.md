# 5. Проверка работы

Проверяйте по частям — так проще найти проблему.

## Шаг 1. Сервер без железа

1. Запустите сервер (агент `my-nfc-webhook` или вручную, см. [02-webhook-server.md](02-webhook-server.md)).
2. Откройте http://localhost:8090. Индикатор **Live** должен гореть зелёным, на карточке — «Поднесите карту к считывателю».
3. Отправьте тестовый скан (агент: «отправь тестовый скан» или PowerShell из раздела 2.3). Карточка должна вспыхнуть, строка — появиться в ленте без перезагрузки страницы.
4. Повторите с **другого устройства в сети** (телефон, ноутбук), заменив `localhost` на IP ПК. Если не работает — брандмауэр (см. 2.5). ESP32 будет стучаться так же, как это устройство.

## Шаг 2. ESP32 без PN532

> Если модуль уже подключён — пропустите этот шаг и переходите к шагу 3 (пункты 3–6).

1. Залейте прошивку, откройте монитор порта (115200).
2. Должна появиться строка `[WiFi] Connected. IP: ...`.
3. Затем `[NFC] PN532 not found (attempt 1/5)` — это ожидаемо, модуль ещё не подключён. После 5 попыток плата перезагрузится.

## Шаг 3. Полная сборка

1. Отключите ESP32 от USB.
2. Выставьте DIP-переключатели PN532 (I2C: 1=ON, 2=OFF) и подключите 4 провода ([04-hardware.md](04-hardware.md)).
3. Подключите USB, откройте монитор порта (115200 бод).
4. Ожидаемый лог:
   ```
   [WiFi] Connected. IP: 192.168.1.57, RSSI: -55 dBm
   [NFC] Found chip PN532, firmware 1.6
   [NFC] Waiting for an ISO14443A card...
   ```
   и 2 вспышки синего LED.
5. Поднесите белую карту или синий брелок:
   ```
   [NFC] Card detected. UID: 3A7F1C09 (4 bytes), MIFARE Classic 1K [ATQA 0004, SAK 08]
   [HTTP] 200 {"status":"ok",...}
   ```
   LED: горит во время отправки, затем одна длинная вспышка.
6. Скан мгновенно появился на веб-мониторе http://localhost:8090.

## Шаг 4. Сценарии

| Проверка | Ожидаемо |
|---|---|
| Держать карту у считывателя 10 с | одна отправка, не десять |
| Убрать карту на 1–2 с и поднести снова | новая отправка |
| Поднести карту, убрать и сразу (быстрее 1 с) поднести снова | одна отправка, в логе `still on reader` |
| Дать карте имя (клик по строке на мониторе) и поднести | на мониторе имя и зелёная вспышка; в логе ESP32 `"known":true` |
| Открыть монитор на телефоне и ПК одновременно | скан появляется на обоих |
| Остановить сервер и поднести карту | `[HTTP] Request failed: connection refused`, 3 коротких вспышки |
| Неверный `WEBHOOK_API_KEY` | `[HTTP] 401 ...`, 3 коротких вспышки |
| Выключить и включить роутер | `[WiFi] Not connected, reconnecting...`, затем работа продолжается |

Проблемы — в [06-troubleshooting.md](06-troubleshooting.md).

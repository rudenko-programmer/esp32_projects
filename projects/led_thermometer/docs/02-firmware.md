# 2. Прошивка

Код: [firmware/led_thermometer/](../firmware/led_thermometer/)

## 2.1 Конфигурация (необязательно)

Wi-Fi не используется, секретов нет. Без `config.h` прошивка берёт значения по умолчанию — они совпадают со схемой в [03-hardware.md](03-hardware.md) и стандартным датчиком NTC 10 кОм / B 3950.

`config.h` нужен, только если меняете пины, схему или подстраиваете датчик:

```powershell
Copy-Item firmware/led_thermometer/config.example.h firmware/led_thermometer/config.h
```

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `SEG_A_PIN` … `SEG_DP_PIN` | GPIO сегментов A–G и точки | 21, 33, 25, 27, 26, 22, 18, 19 |
| `DIGIT1_PIN` / `DIGIT2_PIN` | GPIO анодов левой / правой цифры | 32 / 23 |
| `DIGIT_ON_LEVEL` | `HIGH` — анод напрямую от GPIO; `LOW` — через PNP | `HIGH` |
| `NTC_ADC_PIN` | вход АЦП делителя | 34 |
| `NTC_POWER_PIN` | питание делителя (HIGH); `-1` — делитель от вывода 3V3 | 14 |
| `NTC_R_FIXED` | резистор делителя, Ом | 10000 |
| `NTC_R25` | сопротивление датчика при 25 °C, Ом | 10000 |
| `NTC_BETA` | коэффициент B датчика | 3950 |
| `NTC_SUPPLY_MV` | напряжение питания делителя, мВ | 3300 |
| `TEMP_OFFSET_C` | поправка показаний, °C | 0.0 |
| `TEMP_SAMPLE_MS` / `TEMP_LOG_MS` | период замеров / вывода в лог, мс | 100 / 2000 |

`config.h` в `.gitignore`.

## 2.2 Заливка

1. Arduino IDE: **Файл → Открыть** → `firmware/led_thermometer/led_thermometer.ino`.
2. Плата **DOIT ESP32 DEVKIT V1**, порт `COMx`, **Загрузка**.

Через arduino-cli (из корня монорепы):

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32doit-devkit-v1 projects/led_thermometer/firmware/led_thermometer
arduino-cli upload  --fqbn esp32:esp32:esp32doit-devkit-v1 -p COM5 projects/led_thermometer/firmware/led_thermometer
arduino-cli monitor -p COM5 -c baudrate=115200
```

...
[TEST] все сегменты обеих цифр: должно гореть «8.8.»
[TEST] цифра 1, сегмент A  (ножки 10+ / 3-, GPIO 32 / 21)
...
[TEST] готово, режим «температура»

## 2.4 Команды

В мониторе порта (окончание строки — «Новая строка»):

| Команда | Что делает |
|---|---|
| `c` | температура (режим по умолчанию) |
| `t` | самотест сегментов |
| `0` … `99` | показать число (вернуть температуру — `c`) |
| `h` | справка |

## 2.5 Точность и калибровка

Как считается температура: напряжение на GPIO 34 → сопротивление датчика → °C по формуле B-параметра; замеры каждые 100 мс, по 8 отсчётов, со сглаживанием. На индикаторе — целые градусы с гистерезисом 0,6 °C, чтобы цифра не прыгала 23/24. Подробно — [components/NTC-10k-B3950.md](components/NTC-10k-B3950.md).

Со стандартными значениями точность обычно ±1–2 °C. Если хочется точнее:

| Чем проверили | Что поправить в `config.h` |
|---|---|
| Капля в тающем льду (0 °C) показывает не 0 | `NTC_BETA`: показывает ниже нуля — уменьшить B, выше — увеличить (шаг ~50) |
| Сверили с комнатным термометром, сдвиг на N градусов | `TEMP_OFFSET_C` = разница (например, `-1.5`) |
| Лог показывает сопротивление, а вы знаете точный R25 своего датчика | `NTC_R25` |
